# 連線鎖法分析

以遊戲盤面輸入、三連提示及鎖法成功率為主的 GitHub Pages 靜態工具。

## 使用

- 最上方開始，順時針填入 12 格位置，1–12 各出現一次，支援全形數字。
- 可依序點選 1–12 數字按鈕，自動跳下一個空格；桌面單列、手機四欄三列。
- 點已填位置可修正；選到其他位置已使用的編號時交換兩格。空格填入時已用數字停用，避免重複。

- 點擊編號可鎖定，最多六個，成功率即時更新。
- 橙色代表可擴成值得保留六鎖的三連；可採用三鎖或六鎖。
- 推薦鎖法按鈕可透過游標移入或鍵盤焦點預覽鎖定位置；輸入時會對照盤面位置。

## 面積模型及精確機率

- 所有被線段圍住的封閉區域都計入面積，以正十二邊形為 100%。
- 完整枚舉 19,958,400 個鏡射代表，恢復鏡射後，共 421,560 個組合，成功目錄記錄每種排列的面積。
- 支援 90%–100% 的目標。條件機率為匹配所鎖位置的成功排列數除以 `(12 - 鎖定數)!`。

例如 90% 目標下，六個外框連號的成功率為 `81 / 720 = 11.25%`；只鎖相鄰三個連號則為 `2067 / 362880 ≈ 0.5696%`。

三連包含順時針或逆時針的連號及跨 12 → 1。保留線是同目標下六連基準成功數的三分之一；90% 的保留線為 27/720。此為明確的篩選標準，並非含尋找盤面成本的最佳素材策略。
