# 12 邊形連線模擬器

## 功能

- 數字 1 → 12 → 1 依序連線，採 even-odd 填色並計算覆蓋面積。
- 點擊編號鎖定或解鎖，最多保留 6 個角。
- 均勻隨機重洗未鎖編號，統計次數與素材消耗。
- 預設開啟連線動畫：光點依序繪出 1 → 2 → … → 12 → 1，每段約 0.3 秒。可用「連線動畫」開關立即切換靜態顯示。
- 六鎖時完整枚舉剩餘 720 種排列；未滿六鎖時使用隨機抽樣。
- 可設定目標面積、抽樣次數，並查看成功率與期望追加素材。

## 使用

直接開啟 `index.html`，或透過 https://hsiehston.github.io/connection-simu/ 使用。

## 模型

面積以完整正十二邊形為 100%。每次重洗假設未鎖編號等機率排列，且各次獨立。抽樣未命中不代表成功率為零；期望素材並非保證用量。素材設定沿用原模擬器：0／1／2／3／4／5／6 鎖分別為 10／10／30／60／100／150／220。
