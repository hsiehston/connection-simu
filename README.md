# 連線鎖法分析

以遊戲盤面輸入、三連提示及鎖法成功率為主的 GitHub Pages 靜態工具。

## 使用

- 「盤面順序」可用 ▲／▼ 展開或收合，預設展開，收合不會清空輸入。
- 可依序點選 1–12 數字按鈕，自動跳下一個空格；桌面單列、手機四欄三列。
- 點已填位置可修正；選到其他位置已使用的編號時交換兩格。空格填入時已用數字停用，避免重複。
- 「退回一步」可復原尚未套用的點選、交換、清空或鍵盤編輯；套用及重洗後重新起算輸入復原。
- 觸控裝置預設使用數字按鈕，避免喚出系統鍵盤；可切換「鍵盤輸入」。
- 最上方開始，順時針填入 12 格位置，1–12 各出現一次，支援全形數字。
- 每格按 Enter 跳到下一格並選取內容；第 12 格按 Enter 或按「套用順序」套用。空格、重複或超出範圍會被攔截。
- 「清空」重設輸入並跳到位置 1；重洗後十二格會同步目前盤面。
- 最佳六鎖同時顯示預期平均面積：固定推薦六個位置，平均其餘編號全部 720 種排列的面積，包含未達標結果。
- 點擊編號可鎖定，最多六個。成功率即時更新，無需按分析按鈕。
- 橙色代表可擴成值得保留六鎖的三連；可採用三鎖或六鎖。
- 推薦鎖法按鈕可透過游標移入或鍵盤焦點預覽鎖定位置；輸入時會對照盤面位置。
- 目前面積附目標進度與差距；更多三連及計算說明收合，手機先呈現成功率。
- 動畫預設開啟（系統設定減少動態時預設關閉），每段 150 毫秒。修改 `index.html` 的 `segmentDuration` 可調速度。
- 重洗、解鎖、動畫及素材統計縮成盤面下方一列。

## 面積模型及精確機率

所有被線段圍住的封閉區域都計入面積，以正十二邊形為 100%。
完整枚舉 19,958,400 個鏡射代表，恢復鏡射後，
固定 1 號在最上方有 35,130 個達到 90% 的排列；再恢復十二種旋轉，共 421,560 個。成功目錄記錄每種排列的面積，
支援 90%–100% 的目標。條件機率為匹配所鎖位置的成功排列數除以 `(12 - 鎖定數)!`。

例如 90% 目標下，六個外框連號的成功率為 `81 / 720 = 11.25%`；只鎖相鄰三個連號則為 `2067 / 362880 ≈ 0.5696%`。

三連包含順時針或逆時針的連號及跨 12 → 1。保留線是同目標下六連基準成功數的三分之一；90% 的保留線為 27/720。此為明確的篩選標準，並非含尋找盤面成本的最佳素材策略。

## 檔案

- `index.html`：介面、封閉區域幾何、三連與條件機率、動畫、十二格輸入。
- `success-catalogue.js`：完整高面積排列目錄。
- `.nojekyll`：直接發布靜態檔案。
- `ui-review.html`：320／390／768／1200 px 響應式檢查頁。
